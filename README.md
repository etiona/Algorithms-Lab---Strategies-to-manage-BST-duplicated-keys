# Binary Search Trees: Handling Duplicate Keys

This project explores and experimentally compares three different strategies for handling duplicate keys in Binary Search Trees (BSTs):

* **Standard BST:** duplicate keys are inserted according to a fixed rule.
* **Flag BST:** duplicate keys are distributed between the left and right subtrees using a boolean flag that alternates the insertion direction.
* **List BST:** duplicate keys are stored within the same node using a list-based approach.

The implementations were developed in **Python** and evaluated experimentally using datasets of different sizes and distributions.

The comparison focuses on:

* execution time;
* tree height;
* number of nodes;
* memory usage;
* behavior with increasing input size;
* performance on different input distributions.

The project includes the BST implementations, dataset generation, experimental tests, collected results, and analysis of the different approaches.

**Technologies:** Python, Binary Search Trees, Algorithms & Data Structures, Experimental Analysis
